# React-Projects

Colección de proyectos, aplicaciones completas y ejercicios prácticos desarrollados utilizando **React**. El objetivo principal es documentar el proceso de aprendizaje, explorar nuevas tecnologías en el ecosistema de JavaScript y React, e integrar diferentes herramientas (hooks, componentes funcionales, consumo de APIs, etc.).

## Estructura del Repositorio

